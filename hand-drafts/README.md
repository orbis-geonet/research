# Hand drafts

The original hand-drawn sketches behind the territory-fusion concept, kept here for their historical significance. Before any of the algorithms in this repository were written, the core ideas were worked out with pen on graph paper: amorphous tribal territories, claim circles and how they merge, tangent bridges between nearby claims, collisions with rival territories, and territory centers.

The pages are in no strict order — they are working drawings, not a sequence. The formalized versions of these ideas live in the [worked examples](../examples) and the [live simulation](../simulation-v2).
